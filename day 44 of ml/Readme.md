# Outlier Detection Using the Percentile Method

## What is a Percentile?

A percentile shows the position of a value in a dataset.

* **Minimum** → 0th percentile
* **Median** → 50th percentile
* **Maximum** → 100th percentile

The **Percentile Method** can be used to identify outliers by setting lower and upper percentile limits. Values outside these limits are considered potential outliers.

### Example

Using the **5th and 95th percentiles**:

* Values below the 5th percentile → potential lower outliers
* Values above the 95th percentile → potential upper outliers

This method is simple and useful for detecting unusually low or high values in a dataset.

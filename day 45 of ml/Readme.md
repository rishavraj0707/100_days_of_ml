# Feature Construction, Feature Splitting & Tidy Data

## Feature Construction

Feature construction means **creating new features from existing features** to make data more useful for analysis or machine learning.

**Example:**

* `Date of Birth` → `Age`

## Feature Splitting

Feature splitting means **dividing one feature into multiple features**.

**Example:**

* `Full Name = John Smith`
* `First Name = John`
* `Last Name = Smith`

## Tidy Data

Tidy data follows three simple rules:

* Each **variable** is a column.
* Each **observation** is a row.
* Each **value** is a single cell.

Tidy data makes datasets easier to **understand, analyze, and visualize**.
